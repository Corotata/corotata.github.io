在 iPhone、iPad 或 Mac 上，EPUB翻译官可以整本翻译无 DRM 的 EPUB，并导出原文、译文逐段对照的双语 EPUB。只想读译文时也可导出单语版，两种结果都另存为新文件，原始 EPUB 可以留作备份。

## 选哪种版式

| 版式 | 段落顺序 | 适合 |
| --- | --- | --- |
| 原文＋译文 | 先读原句，再核对意思 | 学外语、读原版 |
| 译文＋原文 | 先读译文，遇到疑问看原句 | 生词较多的长篇 |
| 仅译文 | 全书只显示目标语言 | 想连续读故事 |

## 从 EPUB 到 Apple Books

1. **准备源文件。** iPhone、iPad 上将无 DRM 的 EPUB 存到“文件”，Mac 上放进好找的文件夹。先打开原书，确认正文可读、目录正常。
2. **导入并设定语言。** 选源语言和目标语言，再选双语段落顺序或仅译文。第一次整理图文较多的书，可以先保留原书排版，便于检查译后结构。
3. **联网翻译整本。** 在 App 中选择 Google、Microsoft Edge，或配置自己 API Key 的兼容 AI 服务。完成后抽查人名、术语和章节结尾，确认译文符合自己的阅读习惯。
4. **另存并检查。** 给译后 EPUB 加上能辨认版本的文件名。在 iPhone 或 iPad 从分享菜单打开 Apple Books；在 Mac 可在 Apple Books 使用“文件 → 导入”。检查目录能否跳转，并在常用字号下试读一页。 [Apple 导入说明](https://support.apple.com/en-mk/guide/books/ibkseed72068/mac)

## 常见问题

### 受 DRM 保护的 EPUB 能保持授权直接翻译吗？
输入需要是无 DRM 的 EPUB。受保护的书请向提供方确认是否另有可下载的无 DRM 版本。

### 原文和译文能左右并排吗？
导出的对照是逐段前后排列。字号或屏幕宽度改变时，段落仍按所选顺序阅读。

### PDF 能用这套方法整本翻译吗？
EPUB翻译官的输入格式是无 DRM 的 EPUB。手上只有 PDF 时需要另找适用的工作流程。

### 可以离线翻译吗？
翻译需要联网。兼容 AI 服务还需要你自己的 API Key。

### 会保留目录和原书排版吗？
App 会识别章节，并提供保留原书排版、改横排或改竖排的选项。导出后请用常用阅读器检查目录、插图和段落。
