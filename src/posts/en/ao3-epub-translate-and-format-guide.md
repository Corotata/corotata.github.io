On iPhone or iPad, EPUB Translator can turn a saved AO3 fanfic into a bilingual EPUB with each translation next to its source paragraph in reading order. Open the exported file in EPUB OMG to style text messages as chat bubbles or replace the cover, then read the finished copy in Apple Books.

## Download, translate, and format the fic

1. **Keep a source copy.** When EPUB downloads are available again, choose **Download → EPUB** on the AO3 work page and save it to Files. Keep that original so you can check chapter breaks, names, and author notes.
2. **Translate the whole work.** Import the saved EPUB into EPUB Translator. Set the source and target languages, choose the order of the two languages, and run a translation service while connected to the internet. Read the opening and a later chapter for recurring names and informal dialogue before passing the export to the editor.
3. **Style a message scene.** Open the bilingual export in EPUB OMG. Choose a short text-message exchange and apply chat-bubble formatting to the selected passage. Set speaker names and add avatars if you want them. Keep the paired paragraphs easy to follow, then pick a cover template or image and retain the author's credit.
4. **Check the final reading copy.** Preview and export a fresh EPUB. In Files, use the share sheet to open it in Apple Books. Test a chapter link and read through the message scene at your usual font size.

## FAQ

### Can I paste an AO3 link directly into EPUB Translator?
Start with an EPUB file saved to Files. The workflow uses the downloaded work as its input.

### Does bilingual mode use two columns?
The exported EPUB pairs the original and translation in sequence. You can choose which goes first.

### Will EPUB OMG style all the conversations automatically?
You choose the passages and assign the speaker names. Try one scene before styling the rest of a long fic.

### Will the downloaded book look like the AO3 web page?
Work skins can affect the page without carrying over to the EPUB. Check the saved file for layout and embedded images before editing.

### Does the EPUB update when the author posts a new chapter?
Each download is a snapshot. Keep the formatted copy and save a fresh original when you want the latest chapters.
