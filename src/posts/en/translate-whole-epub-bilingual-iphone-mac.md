EPUB Translator takes a DRM-free EPUB on iPhone, iPad, or Mac and translates the whole book in one job. It exports a new EPUB with the source and translation paired paragraph by paragraph, or with just the translation. Keep the original file so you can compare editions later.

## Pick a layout before translating

| Layout | Reading order | Best for |
| --- | --- | --- |
| Original + translation | Read a source paragraph, then its translation | Studying a language or checking wording |
| Translation + original | Read the translation first, with the source below it | Following a book with unfamiliar vocabulary |
| Translation only | Read just the target language | Uninterrupted reading |

## Translate and verify one book

1. **Open a DRM-free source file.** Save the EPUB in Files on iPhone or iPad, or in a folder on Mac. Open the original and check that it contains readable text and the chapters you expect.
2. **Import the EPUB and choose both languages.** Select the source and target languages, then choose the layout. If the book has an unusual layout or many illustrations, start with the option to retain the original formatting.
3. **Choose a translation service and run the job online.** The app offers Google, Microsoft Edge, and compatible AI services configured with your own API key. Spot-check names, recurring terms, and an opening and closing paragraph from different chapters.
4. **Export and test the new EPUB.** Save it under a name that identifies the language pair. On iPhone or iPad, share the exported file to Apple Books. On Mac, use **File → Import** in Apple Books. Jump to a chapter in the middle and check the layout at your usual reading size. [Apple Books import instructions](https://support.apple.com/en-mk/guide/books/ibkseed72068/mac)

## FAQ

### Can I translate an EPUB and keep its original DRM?
The app accepts DRM-free EPUB files. For a protected copy, ask the seller or publisher whether a DRM-free edition is available.

### Can I read the original and the translation side by side?
In this export, parallel text means paired paragraphs in sequence. You can put either language first.

### Do I need an internet connection or API key?
Translation needs internet access. You supply your own API key when you choose a compatible AI service.

### Can I import a PDF instead?
EPUB Translator takes EPUB as input. A PDF requires a separate workflow.

### Can I keep my table of contents and reading direction?
The app reads chapter information and lets you retain the source layout or choose horizontal or vertical writing. Test the exported navigation and layout in your reader.
