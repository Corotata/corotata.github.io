DRM이 없는 EPUB은 iPhone, iPad, Mac의 EPUB 전자책 번역기에서 한 권 통째로 번역할 수 있습니다. 원문과 번역문이 문단마다 이어지는 대조본을 만들거나 번역문만 담긴 새 EPUB을 내보낼 수 있습니다.

## 읽기 편한 번역문 배치 고르기

| 내보내기 방식 | 읽는 순서 | 이런 경우에 적합 |
| --- | --- | --- |
| 원문 다음 번역문 | 원문을 읽고 한국어 번역 확인 | 외국어 공부를 하며 뜻을 확인하고 싶을 때 |
| 번역문 다음 원문 | 한국어로 읽다가 원문 확인 | 어휘가 어려운 소설의 줄거리를 따라가고 싶을 때 |
| 번역문만 | 번역된 언어로 끝까지 읽기 | 한 언어로 끊김 없이 읽고 싶을 때 |

## 파일을 가져와 번역하고 읽는 순서

1. **원본 EPUB을 확인합니다.** iPhone이나 iPad에서는 ‘파일’ 앱에, Mac에서는 원하는 폴더에 DRM이 없는 EPUB을 저장합니다. 원본을 열어 본문이 읽히는지, 목차에서 장으로 이동할 수 있는지 살펴보세요.
2. **언어와 배치를 설정합니다.** EPUB을 가져온 뒤 원문 언어와 번역할 언어를 고릅니다. 삽화가 많거나 세로쓰기로 된 책이라면 우선 원본 레이아웃을 유지한 상태로 시도해 보세요.
3. **번역 서비스를 선택합니다.** 인터넷에 연결한 상태에서 Google이나 Microsoft Edge를 선택하거나, 개인 API 키로 호환되는 AI 번역 서비스를 설정합니다. 번역한 뒤 여러 장을 열어 인물 이름과 자주 나오는 용어가 일관적인지 확인하세요.
4. **새 EPUB을 내보냅니다.** 파일 이름에 ‘영한 대조’처럼 언어를 표시하면 원본과 구분하기 쉽습니다. iPhone과 iPad에서는 공유 메뉴로 Apple Books에 보내고, Mac에서는 Apple Books의 파일 메뉴에서 가져옵니다. 중간 장으로 이동해 문단 순서와 글자 배치를 확인합니다.

## 자주 묻는 질문

### 서점에서 구매한 DRM 보호 EPUB도 번역할 수 있나요?
DRM이 없는 EPUB을 가져올 수 있습니다. 보호된 파일이라면 구매처나 출판사에 DRM이 없는 판본이 있는지 문의하세요.

### 원문과 번역문을 두 열로 나란히 볼 수 있나요?
내보낸 EPUB에서는 두 언어의 문단이 차례대로 나옵니다. 먼저 표시할 언어는 직접 선택할 수 있습니다.

### 인터넷 연결과 API 키가 모두 필요한가요?
번역할 때는 인터넷에 연결해야 합니다. 개인 API 키는 호환되는 AI 번역 서비스를 선택할 때 준비하면 됩니다.

### PDF 전자책도 가져올 수 있나요?
이 앱의 입력 형식은 EPUB입니다. PDF 번역에는 PDF를 지원하는 도구가 필요합니다.

### 목차와 가로쓰기·세로쓰기 설정은 어떻게 되나요?
원래 레이아웃을 유지하거나 가로쓰기와 세로쓰기 중 하나를 선택할 수 있습니다. 내보낸 뒤 평소 쓰는 전자책 앱에서 목차 링크와 글줄 방향을 확인하세요.
