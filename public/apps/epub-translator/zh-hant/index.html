EPUB翻譯官

外文小說整本翻譯，原文譯文對照

適用裝置：iPhone / iPad / Mac

EPUB翻譯官是一款 iPhone、iPad 和 Mac 上的 App，把整本外文 EPUB 電子書翻譯成另一種語言，匯出新的 EPUB：原文和譯文逐段對照的雙語版，或只有譯文的版本。

在 App Store 下載含 App 內購買項目

適合誰

  • 想讀一本還沒有中文譯本的外文書
  • 用原版小說學外語，原文譯文對照著讀
  • 愛看英文、日文、韓文小說、網文和輕小說

怎麼用

  1. 從「檔案」匯入無 DRM 的 EPUB
  2. 選擇來源語言和目標語言
  3. 選擇版式：原文+譯文、譯文+原文，或僅譯文
  4. 用 Google、Microsoft Edge，或填入自己 API Key 的 AI 翻譯服務，翻譯整本書
  5. 匯出新的 EPUB，在 Apple Books、Kindle 等閱讀器裡繼續讀

核心功能

  • 整本翻譯，不用一頁頁複製貼上
  • 雙語對照版或僅譯文版
  • 識別書名、作者、封面和章節
  • 保留原書排版，也可改為橫排或直排
  • iPhone、iPad、Mac 都能用

常見問題

能翻譯 PDF 嗎？

不能。支援無 DRM 的 EPUB 檔案，不支援 PDF。

使用哪些翻譯服務？

可使用 Google、Microsoft Edge，或填入自己 API Key 的 AI 翻譯服務。翻譯需要連網；AI 服務需要你自己的 API Key，譯文品質取決於所選的翻譯服務。

翻譯後會得到什麼？

匯出新的 EPUB：原文和譯文逐段對照的雙語版（原文+譯文或譯文+原文），或只有譯文的版本。可保留原書排版，也可改為橫排或直排。

支援哪些裝置？

iPhone、iPad、Mac 都能用。

須知

  • 支援無 DRM 的 EPUB 檔案，不支援 PDF。
  • 翻譯需要連網；AI 服務需要你自己的 API Key。
  • 譯文品質取決於所選的翻譯服務。
