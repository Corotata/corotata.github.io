EPUB翻译官

原版书翻译，生成原文译文对照版

适用设备：iPhone / iPad / Mac

EPUB翻译官是一款 iPhone、iPad 和 Mac 上的 App，把整本外文 EPUB 电子书翻译成另一种语言，导出新的 EPUB：原文和译文逐段对照的双语版，或只有译文的版本。

在 App Store 下载含 App 内购买

适合谁

  • 想读一本还没有中文译本的外文书
  • 用原版小说学外语，原文译文对照着读
  • 爱看英文、日文、韩文小说、网文和轻小说

怎么用

  1. 从“文件”导入无 DRM 的 EPUB
  2. 选择源语言和目标语言
  3. 选择版式：原文+译文、译文+原文，或仅译文
  4. 用 Google、Microsoft Edge，或填入自己 API Key 的 AI 翻译服务，翻译整本书
  5. 导出新的 EPUB，在 Apple Books、Kindle 等阅读器里继续读

核心功能

  • 整本翻译，不用一页页复制粘贴
  • 双语对照版或仅译文版
  • 识别书名、作者、封面和章节
  • 保留原书排版，也可改为横排或竖排
  • iPhone、iPad、Mac 都能用

常见问题

能翻译 PDF 吗？

不能。支持无 DRM 的 EPUB 文件，不支持 PDF。

用什么翻译服务？

可使用 Google、Microsoft Edge，或填入自己 API Key 的 AI 翻译服务。翻译需要联网；AI 服务需要你自己的 API Key，译文质量取决于所选的翻译服务。

翻译后得到什么？

导出一本新的 EPUB：原文和译文逐段对照的双语版（原文+译文或译文+原文），或只有译文的版本。可保留原书排版，也可改为横排或竖排。

支持哪些设备？

iPhone、iPad 和 Mac 都能用。

须知

  • 支持无 DRM 的 EPUB 文件，不支持 PDF。
  • 翻译需要联网；AI 服务需要你自己的 API Key。
  • 译文质量取决于所选的翻译服务。
