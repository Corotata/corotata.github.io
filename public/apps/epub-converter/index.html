EPUB转文档

EPUB转Word、PDF、TXT与Markdown

适用设备：iPhone / iPad

EPUB转文档是一款专注于电子书内容转换的本地工具，可将无 DRM 的 EPUB 文件转换为 Word、PDF、TXT 和 Markdown。

在 App Store 下载含 App 内购买

无论你是希望继续编辑电子书内容、打印学习资料、整理个人知识库，还是提取 EPUB 中的封面和插图，都可以通过简单的几个步骤完成。

主要功能

  • EPUB 转 Word

生成可继续编辑的 DOCX 文档，保留可解析的章节、正文和图片内容。

  • EPUB 转 PDF

将电子书整理为便于分享、批注和打印的 PDF 文件。

  • EPUB 转 TXT

提取章节与正文，生成简洁的纯文本文件。

  • EPUB 转 Markdown

生成 Markdown 文件，并可额外导出包含 Markdown 与图片资源的 ZIP 文件包。

  • 提取书内图片

浏览 EPUB 中可解析的封面和插图，支持单张查看与多选导出。

  • 本地转换

EPUB 解析和文档生成均在设备本地完成，无需上传电子书内容。

使用方法

  1. 从系统“文件”中选择一本 EPUB
  2. 选择 Word、PDF、TXT 或 Markdown
  3. 等待本地转换完成
  4. 预览并保存生成的文件

适用场景

  • 将 EPUB 书稿转换为 Word 继续修改
  • 将电子书转换为 PDF 进行批注或打印
  • 将 EPUB 内容整理为 Markdown 知识库素材
  • 提取小说、教材和电子书中的封面或插图
  • 在不上传文件的情况下完成格式转换

每位新用户可免费完成 3 次成功转换。升级 EPUB Converter Pro 后，可解锁无限导出。

转换结果取决于源 EPUB 的结构与内容。本应用不支持受 DRM 保护的电子书，也不承诺完整保留原 EPUB 的字体、CSS 或复杂版面。

常见问题

可以转换成哪些格式？

可将无 DRM 的 EPUB 转换为 Word、PDF、TXT 和 Markdown。Markdown 还可额外导出包含 Markdown 与图片资源的 ZIP 资源包。

电子书会上传到服务器吗？

不会。EPUB 解析与文档生成均在设备本机完成，不需要上传电子书内容。

能转换受 DRM 保护的电子书吗？

不能。本应用不支持受 DRM 保护的电子书，也不保证完整保留原 EPUB 的字体、CSS 或复杂版面；转换结果取决于来源 EPUB 的结构与内容。
