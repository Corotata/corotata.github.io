EPUB Converter

Markdown & image export

Works on：iPhone / iPad

EPUB Converter is an on-device utility that converts DRM-free EPUB books into Word, PDF, TXT, and Markdown files.

Download on the App StoreIncludes in-app purchases

Use it when you need to edit book content, print study material, move a book into a Markdown knowledge base, or extract covers and illustrations from an EPUB file.

KEY FEATURES

  • EPUB to Word

Create an editable DOCX document with supported chapters, text, and images.

  • EPUB to PDF

Generate a PDF that is easier to share, annotate, and print.

  • EPUB to TXT

Extract chapter titles and body text into a clean plain-text file.

  • EPUB to Markdown

Create a Markdown file and an additional ZIP package containing the Markdown document and its image assets.

  • Extract book images

Browse supported covers and illustrations, preview individual images, and export one or multiple files.

  • On-device conversion

EPUB parsing and document generation take place on your device. Your book does not need to be uploaded for conversion.

FAQ

Which formats can it convert to?

EPUB Converter turns DRM-free EPUB files into Word, PDF, TXT and Markdown. Markdown can also be exported as a ZIP package with images.

Are my ebooks uploaded to a server?

No. EPUB parsing and file generation happen on your device, so book content is not uploaded.

Can it convert DRM-protected books?

No. DRM-protected ebooks are not supported, and the original fonts, CSS or complex layouts are not guaranteed to be preserved. Results depend on the structure of the source EPUB.

Is it free to use?

Every new user can complete 3 successful conversions for free. Upgrading to EPUB Converter Pro unlocks unlimited exports.

HOW IT WORKS

  1. Select an EPUB from the system file picker
  2. Choose Word, PDF, TXT, or Markdown
  3. Wait for the on-device conversion to finish
  4. Preview and export the generated file

USE EPUB CONVERTER TO

  • Turn an EPUB manuscript into an editable Word document
  • Convert an ebook to PDF for annotation or printing
  • Move EPUB content into a Markdown knowledge base
  • Extract covers and illustrations from books or study material
  • Convert private files without uploading them to a conversion server

Every new user can complete three successful conversions at no charge. Upgrade to EPUB Converter Pro to unlock unlimited exports.

Results depend on the structure and content of the source EPUB. The app does not support DRM-protected ebooks and does not promise pixel-perfect preservation of EPUB fonts, CSS, or complex layouts.
