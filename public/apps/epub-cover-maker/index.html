精美封面模板，修改书名、作者与出版社

为已有 EPUB 快速制作更契合的书籍封面，或直接替换原封面。 在 iPhone、iPad 和 Mac 上一站式完成封面制作、书籍信息修改、排版方向调整与重新导出。

核心功能

多方式封面制作与比例优化

  • 相册与文件选图：从照片图库或文件系统中选取任意高质量图片设为封面。
  • 提取书内插图：智能扫描并提取 EPUB 内部所有插图，一键设为封面。
  • 排版封面模板：内置多款无图极简与文艺排版模板，输入书名与作者即刻生成专业封面。
  • AI 提示词助手：根据书籍信息生成针对性的绘图提示词，方便前往主流 AI 平台创作专属封面。
  • 主流阅读器比例：支持原始比例、7:10、2:3、3:4、5:8 等主流电子书比例，提供 Fit（完整显示）与 Fill（裁切填满）即时预览。
  • 智能体积压缩：替换高清大图时自动压缩超大图片，保持封面清晰的同时大幅减少 EPUB 导出体积。

标准 EPUB 元数据（OPF）与丛书管理

  • 完整书籍信息：修改书名、作者、出版社、分类标签（Subjects）及内容简介。
  • 丛书/系列管理：支持设置丛书名称（Series）与卷号索引（Series Index / Volume），让系列藏书井井有条。
  • 标准规范兼容：严格遵循 EPUB 2 / EPUB 3 标准 OPF 规范写入，兼容各类主流阅读设备。

排版方向与段首缩进

  • 横排/竖排转换：支持一键将书籍转换为竖排直排（右翻页，基于 CSS writing-mode），重现经典排版美感，亦支持转回横排。
  • 段落两字缩进：自动为未缩进段落添加首行两个字符缩进，已含缩进的段落智能跳过。
  • 规范化清理：优化与规范章节 XHTML 结构，阅读显示更加整齐统一。

无损导出与便捷无线传书

  • 本地保存：直接导出到 iOS“文件”应用或 macOS 文件夹。
  • 应用与阅读器分享：无缝分享到 Apple 图书、微信读书、Kindle、Kobo、Readmoo、文石 BOOX 等应用。
  • 局域网 Wi-Fi 网页传书：无需数据线，内置局域网 HTTP 网页传输服务，手机生成二维码或局域网网址，墨水屏阅读器扫码或浏览器访问即可秒速下载。
  • Kindle 邮箱辅助：支持通过邮件将处理完成的 EPUB 发送至 Kindle 个人文档。
  • 专业版权益：在编辑页查看剩余免费导出次数，随时了解专业版的不限次数导出权益。

隐私安全与本地离线处理

  • 纯本地处理：EPUB 解包、封面注入、元数据修改与重新打包完全在设备本地进行。
  • 零云端上传：电子书文件绝不上传至任何第三方服务器，彻底保护您的个人阅读隐私。

常见问题

这款 App 可以编辑章节正文内容或转换 TXT/PDF 吗？

本 App 专注于 EPUB 的封面设计、元数据管理、排版方向转换与打包传输，不支持正文段落文字的直接编辑，也不支持从 TXT 或 PDF 转换生成 EPUB。

局域网 Wi-Fi 传书如何使用？

只要您的手机/电脑与电子书阅读器（如 Kindle、Kobo、BOOX 等）连接在同一个 Wi-Fi 网络下，开启传书功能后，用阅读器扫描二维码或在阅读器内置浏览器输入提示的网址即可直接下载 EPUB。

替换高分辨率图片会导致电子书文件变得非常巨大吗？

App 内置智能图片压缩功能，会在确保电子书阅读器高分辨率屏幕清晰显示的前提下，自动优化压缩图片体积。
